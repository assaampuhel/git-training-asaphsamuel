# Memory Match Game

A fun, interactive browser-based memory matching game built with HTML, Vanilla JavaScript, and Tailwind CSS. Test your memory by finding all matching pairs of tech-related icons!

## 🎮 Features

- **24-Card Deck:** 12 unique pairs of technology icons (HTML, CSS, JS, React, Tailwind CSS, Python, C++, Git, GitHub, etc.) to match.
- **3D Animations:** Smooth, visually appealing card flip animations using CSS 3D transforms with Tailwind utility classes.
- **Winning Celebration:** A rewarding confetti explosion when all matches are found, powered by `canvas-confetti`.
- **Responsive Design:** A clean layout that adapts beautifully to different screen sizes.

## 🛠️ Tech Stack

- **HTML5** for structure.
- **Tailwind CSS** for styling and animations.
- **Vanilla JavaScript** for game logic and DOM manipulation.
- **canvas-confetti** library for the winning effect.

## 🚀 Getting Started

### Prerequisites

You need Node.js installed to compile the Tailwind CSS file.

### Installation & Setup

1. **Clone or download the project** to your local machine.
2. **Install dependencies:** Open your terminal in the project directory and run:
   ```bash
   npm install
   ```
3. **Compile Tailwind CSS:** To start the Tailwind CLI build process in watch mode, run:
   ```bash
   npm run dev
   ```
   *(Alternatively, run `npm run build` to build the CSS once for production).*
4. **Play the game:** Open `dist/index.html` in your favorite web browser to start playing!

## 📂 File Structure

- `src/input.css`: The main CSS file where Tailwind directives are injected.
- `dist/index.html`: The main HTML file containing the game structure.
- `dist/style.css`: The compiled CSS file generated by Tailwind.
- `dist/script.js`: The custom game logic in Vanilla JavaScript.
- `dist/assets/icons/`: Directory containing the tech icon images.
